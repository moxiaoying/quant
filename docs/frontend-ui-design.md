# 量化管理系统前端 UI 设计说明

## 1. 设计定位

采用“桌面端量化工作台”设计，优先满足高信息密度、快速筛选、状态可见和交易安全。默认深色主题，支持后续浅色主题。

```text

```

下单区域：


点击“提交订单”必须显示二次确认：账户、标的、方向、价格、数量、金额、风控结果和环境。

## 4. 组件规范

### 状态标签

```text
运行中：蓝/绿
已完成：绿色
待执行：灰色
执行中：蓝色
异常：红色
警告：橙色
```

### 表格规范

- 首列固定业务主键或标的名称。
- 金额右对齐，统一两位或四位小数。
- 时间显示到秒，并显示数据更新时间。
- 支持分页、排序、筛选、列显示配置和导出。

### 图表规范

- 收益曲线默认显示累计收益和基准线。
- K 线支持十字光标、缩放和时间范围切换。
- 回撤图使用独立区域，不与收益图混用。
- 图表异常时显示数据更新时间和错误原因。

## 5. 前端状态管理

建议迁移到 Vue 3 + TypeScript 后建立以下 Store：

```text
authStore       登录用户、Token、权限
marketStore     当前标的、行情、K线
accountStore    账户、资金、持仓
strategyStore   策略、信号、策略状态
orderStore      订单、成交、撤单
riskStore       风控状态、告警、紧急停止
taskStore       任务、进度、日志
```

## 6. 响应式策略

- 桌面端：完整工作台，支持交易和回测。
- 平板端：保留行情、持仓、报表和告警。
- 手机端：默认只读，支持告警确认和紧急停止；不默认开放实盘下单。
